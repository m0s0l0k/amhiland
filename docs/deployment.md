# Déploiement

Le site produit des fichiers statiques dans `dist/`, publiables sur un hébergeur statique compatible. Le fournisseur et le domaine restent à sélectionner et configurer.

La CI GitHub vérifie les changements avant publication. Aucun déploiement automatique n’est configuré dans ce socle ; il sera ajouté après choix de l’hébergeur et de ses environnements. Conserver des prévisualisations par pull request et limiter les permissions de publication au nécessaire.

Retour arrière : redéployer la dernière version validée ou revenir à une révision connue du dépôt via la plateforme choisie.
