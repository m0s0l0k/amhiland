# ADR 0001 : démarrer en statique

- **Statut :** accepté
- **Décision :** la V1 est un site Astro pré-rendu, sans backend ni base de données.
- **Contexte :** le périmètre initial est éditorial et ne nécessite pas de données utilisateurs.
- **Conséquences :** hébergement et exploitation simples ; les capacités dynamiques seront ajoutées au besoin, derrière des interfaces explicites, avec décisions propres sur sécurité, données et coûts.
